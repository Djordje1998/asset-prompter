# Code of conduct

Be kind and be concrete. Report what you saw, not who you think is at fault. Help newcomers with a preset or a first issue the way you would like to be helped.

No harassment, insults or personal attacks in issues, pull requests or anywhere this project is discussed. The maintainer removes such content and may block the account; repeated or serious cases are reported to GitHub.

If something here made you uncomfortable, write to the maintainer through a [private report](https://github.com/Djordje1998/asset-prompter/security/advisories/new) or an issue, whichever you prefer.
