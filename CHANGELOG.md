# Changelog

## 0.1.0 (6 October 2026)

The first release.

- A local web app and a project folder carry prompts and results between a coding agent and the generator a person uses by hand.
- The agent writes slot and version files; the person generates, drops results, approves or asks for changes; the agent reviews every result first.
- Videos get frame sheets, a motion map, a first/last frame comparison and motion numbers for the agent, with ffmpeg.
- Notify agent wakes a waiting agent with a briefing of everything that is now its turn.
- Presets for seven generators: ChatGPT Images, Dreamina, Google Flow, Grok Imagine, Leonardo.Ai, Luma Dream Machine and Midjourney, checked in October 2026.
- A tutorial in the app, project and slot trash with undo, slot cloning, exports of the final asset.
- Setup scripts for Windows and Linux, and instructions an agent can follow to install it.
